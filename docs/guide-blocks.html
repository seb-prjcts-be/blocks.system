guide 02 · middle

shape the blocks

Add trusted HTML, a DOM node or a factory. Then configure each returned block.

01start 02blocks 03finish

three content forms

const blockHtml = blocks.add("<p>trusted html</p>", {
  id: "block-html"
});

const blockCanvasNode = document.createElement("canvas");
const blockCanvas = blocks.add(blockCanvasNode, {
  id: "block-canvas"
});

const blockButton = blocks.add(function () {
  const blockButtonNode = document.createElement("button");
  blockButtonNode.textContent = "native control";
  return blockButtonNode;
}, { id: "block-button" });

HTML strings become markup. For untrusted text, create a DOM node and set textContent.

one block, one controller

blockCanvas.menu("canvas", {
  close: true,
  minimize: true
});
blockCanvas.span(2, 1);
blockCanvas.place(2, 1);
blockCanvas.variant = "blue";
blockCanvas.minimized = false;

// later
blockCanvas.remove();

blocks owns the field and grid. A block… controller owns its menu, span, place, variant, minimized state and removal.
