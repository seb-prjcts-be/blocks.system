# blocks.system v0.4.2

`v0.4.2` is the verified release-boundary correction for `v0.4.1`. The public
JavaScript, minified JavaScript, CSS and TypeScript contracts are unchanged and
remain byte-identical to `v0.4.0` and `v0.4.1`.

## Fixed

- The browser suite now derives the visible documentation source label from
  `docsSourceLabel()` instead of hardcoding the former `main · unreleased`
  state.
- The documentation and browser-harness fixes recorded for `v0.4.1` are carried
  into a tag whose complete post-tag gate can finish green.

## Release boundary

The immutable `v0.4.1` tag remains in history, but it was not promoted to a
GitHub Release after its tag run exposed the stale browser expectation. Public
installation snippets therefore advance directly from `v0.4.0` to `v0.4.2`.
