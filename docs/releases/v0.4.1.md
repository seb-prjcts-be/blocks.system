# blocks.system v0.4.1

`v0.4.1` is a documentation and verification patch over `v0.4.0`. The public
JavaScript, CSS and TypeScript contracts are unchanged.

## Fixed

- Reference tables no longer receive an unnecessary inner vertical scrollbar
  when their content fits; the page remains the single scrolling surface.
- The browser harness now handles repeated navigation to an identical URL
  explicitly, preventing a false timeout in the full layout suite.
- Development documentation now describes the draggable reference and the
  canonical `main`-only project workflow accurately.

## Verification

- The complete static, TypeScript, docs-contract and real-browser layout suite
  runs against the release candidate before the immutable tag is created.
- The tagged core module, minified module, stylesheet and declarations remain
  byte-identical to `v0.4.0`.
