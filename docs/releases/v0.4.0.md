# blocks.system v0.4.0

`v0.4.0` makes layout behavior explicit, adds an addressless responsive grid
and brings the runtime, TypeScript declarations, manual, API reference and
immutable CDN snippets back onto one release boundary.

## Breaking changes

- Replaced the legacy `snap` option and `block.flow()` method with one immutable
  `layout`: `free`, `fixed-grid` or `flow-grid`. The intermediate `placement`
  option was discarded before release so it cannot become a second switch.
- Resizing is one system-level capability and is accepted only with
  `layout: "flow-grid"`; the intermediate per-block `resizable` option was
  discarded before release.
- `setGrid()` and `span()` reject `free`; `place()` and `compact()` reject every
  mode except `fixed-grid`. Invalid combinations now fail at creation or call
  time instead of producing a hybrid state.
- Layout snapshots include their layout mode and can only be restored into a
  system with that same mode.

## Added

- `flow-grid`: blocks follow DOM order, use only an initial span and reflow
  automatically after reorder, minimize, resize or removal.
- Optional inline resize lines for non-minimized flow-grid blocks, with pointer
  and keyboard control plus a `blocks:resize` event.
- `exportLayout()` and `restoreLayout()` for content-free order, spans, optional
  fixed positions and minimized state. A `localStorage` recipe documents simple
  per-browser personal layouts; account-level content still belongs in server
  storage such as SQLite.
- Local Instrument Sans font files and their SIL Open Font License, so the docs
  no longer depend on Google Fonts.

## Changed

- Fixed-grid removal now preserves empty addresses until an explicit
  `compact()`; flow-grid continues to close gaps automatically.
- In flow-grid a minimized block becomes one titlebar row while keeping its DOM
  order. In fixed-grid it retains its assigned footprint.
- Colored and inverted blocks keep their content surface neutral: color belongs
  to the titlebar, with a thin black outline that grows on hover.
- The manual and reference use a smaller shared CSS surface, generated reference
  fallback and interactive examples instead of the retired examples section.

## Migration

1. Replace `{ snap: true }` or `{ placement: "fixed" }` with
   `{ layout: "fixed-grid" }`.
2. Replace `{ placement: "flow" }` and any `block.flow()` calls with one system
   created as `{ layout: "flow-grid" }`.
3. Move per-block resize choices to `{ layout: "flow-grid", resizable: true }`
   on the system.
4. Include the exported `layout` field when persisting snapshots, and restore a
   snapshot only into the same layout mode.

This project remains `private: true`: distribution is the GitHub release tag
and its jsDelivr ESM/CSS URLs, not npm.
