api

small surface, clear ownership

General state is available on blocks.system. Object state is available on the controller returned by add().

system layout

memberreturnspurpose
attach(target)systemAttach to a selector or DOM element.
setGrid(x, y)systemSet positive integer column and row counts.
snapbooleanRead or change grid snapping.
draggablebooleanEnable reordering blocks by dragging their menu bars.
fieldelement|nullRead the currently attached field.
add(content, options)blockAdd HTML, a DOM node or a content factory.

block object

memberreturnspurpose
idstringStable lowercase kebab-case object id.
elementsectionOuter block element.
contentdivContent host inside the block.
menu(name, close)blockAdd or update a title bar and optional close button.
colorstringRead or set the object colour CSS value.
remove()trueRemove the object from its field.

definitions and adapters

memberreturnspurpose
register(definition)systemRegister a reusable lowercase kebab-case definition.
registerAdapter(id, adapter)systemRegister a lifecycle adapter with at least mount().
list(filters)arrayList definitions by query, adapter, medium or category.
get(id)definition|nullRead one registered definition.
listAdapters()arrayList registered adapter ids.
mount(id, target, overrides)promise<element>Mount one definition through its adapter.
unmount(target)booleanRun optional cleanup and remove mounted content.
remount(id, target, overrides)promise<element>Mount again with new settings.
snippet(id, overrides)stringAsk an adapter for a reusable snippet.
address(id)urlCreate a catalog URL using ?block=id.

definition shape

{
  id: "welcome",
  label: "welcome",
  adapter: "note",
  medium: "html",
  category: "text",
  description: "a small note",
  defaults: { text: "hello" },
  attributes: [],
  requires: []
}

errors

The library throws early for invalid ids, missing fields, invalid grid values, duplicate registrations, unknown blocks and incomplete adapters. Catch only errors you can recover from.
