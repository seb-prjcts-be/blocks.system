guide 01 · start

make one block

Load the core, attach one field, add one block. That is the whole start.

01start 02blocks 03finish

the essential example

<link rel="stylesheet" href="./blocks.system.css">

<div id="blocks-field"></div>

<script type="module">
  import { system as blocks } from "./blocks.system.mjs";

  blocks.attach("#blocks-field");
  blocks.setGrid(4, 2);
  blocks.snap = true;
  blocks.draggable = true;

  const blockHello = blocks.add("<p>hello</p>", {
    id: "block-hello"
  });
  blockHello.menu("hello", { close: true });
  blockHello.span(2, 1);
  blockHello.place(1, 1);
</script>

Naming rule: use blocks for the shared system and start every returned controller with block, such as blockHello. The browser-global equivalent remains window.blocks.system.

what happened

  1. attach

    blocks.attach() claims one explicit field, never the whole page.

  2. configure

    blocks.setGrid() sets columns and rows.

  3. add

    blocks.add() returns one controller: blockHello.
