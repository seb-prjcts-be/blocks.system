one field, four kinds of object

The field is one div. On this site black is the easy default; pure RGB/CMY colours mark only a few exceptions.

blocks.system.attach("#field");
blocks.system.setGrid(4, 1);
blocks.system.snap = true;
blocks.system.draggable = true;
quick start

the object is the interface

System-wide choices stay under blocks.system. Individual choices stay under the returned block.

import { system } from "./blocks.system.mjs";

blocks.system.attach("#field");
blocks.system.setGrid(3, 2);
blocks.system.snap = true;
blocks.system.draggable = true;

const block = blocks.system.add(content);
block.menu("test", true);
block.color = "red";
